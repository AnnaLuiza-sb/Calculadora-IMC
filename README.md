# 🖩 Calculadora-IMC

### Descrição

Este é um projeto web interativo que simula o sistema de uma clínica médica para analisar o IMC (Índice de Massa Corporal) de um grupo de pacientes. O usuário insere os dados (nome, peso e altura), e o sistema:

- Calcula o IMC individualmente

- Classifica o grau de obesidade de cada paciente

#

### Funcionalidades

✅ Cadastro de múltiplos pacientes

✅ Cálculo automático do IMC

✅ Classificação do grau de obesidade

✅ Interface amigável e responsiva

#

### 👩🏽‍💻 Tecnologia utilizadas

- HTML
- CSS
- JAVASCRIPT
